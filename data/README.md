# Processed training data

This folder releases the processed MCA-labeled training dataset and the fixed
cross-validation splits used in the manuscript, sufficient to retrain and evaluate the
reported models together with the code in `features/` and `models/`. The raw DFT
calculation files underlying the MP-derived labels cannot be redistributed under the
research-collaboration agreement and remain available from the corresponding author on
reasonable request (see `../DATA_AVAILABILITY.md`).

## `structure_property_table.csv` (2,762 rows)

| Column | Description |
|---|---|
| `entry_id` | Materials Project id (`mp-…`) or Novamag entry id (`<formula>_#<SG>_<n>.json`). |
| `source` | Label provenance: `MP structure; K_eff from this work (DFT)` — anisotropy computed in this work with the three-axis protocol (`descriptor/`) on industrial computational resources; or `Novamag database (Nieves et al. 2019)` — K1/easy-axis labels taken from the public Novamag database. |
| `formula` | Chemical formula as used in the pipeline label files. |
| `space_group_number` | MP entries: spglib/pymatgen `SpacegroupAnalyzer` (symprec = 0.1) on the released structure. Novamag entries: space group encoded in the entry id. |
| `K_eff_MJ_per_m3` | Effective magnetocrystalline-anisotropy label (MJ m⁻³). Uniaxial entries: signed K1-type value (negative = easy-plane). Low-symmetry entries: K_eff as defined in the manuscript. |
| `mu0_Ms_T` | μ₀Mₛ (T) for MP entries (Materials Project values, as used for κ in the screening). Empty for Novamag entries; saturation magnetization for those entries is available from the Novamag database. |
| `easy_axis_label` | Classification label, `(K_eff ≥ 0)` as integer — only for entries in the classification (uniaxial) set; empty otherwise. |
| `in_classification_set` | 1 if the entry is one of the 1,323 uniaxial entries used to train the easy-axis classifier. |
| `in_regression_set` | 1 if the entry is one of the 2,077 entries (easy-axis uniaxial + low-symmetry) used to train the K_eff regressor. |
| `cif_file` | Path of the released structure file under `data/`. Empty for three MP entries (`mp-17467`, `mp-558960`, `mp-578610`) that are deprecated in the current MP release; their labels are retained and the structures are available through MP legacy ids. |

## `structures/` (2,759 CIF files)

Crystal structures of the training entries: 1,732 Materials Project structures
(CC BY 4.0, https://materialsproject.org) and 1,027 Novamag structures
(P. Nieves et al., *Comput. Mater. Sci.* 2019, http://crono.ubu.es/novamag/).

## `cv_splits/`

Exact 5-fold cross-validation assignments reproducing the splits used in the manuscript
(generated by scikit-learn with `shuffle=True, random_state=42` over the row order of the
feature tables after `dropna()`, as in `models/train_classifier_regressor.py`):

- `regression_folds.csv` — 2,077 rows (`row_index`, `entry_id`, `fold` 1–5); `KFold`.
- `classification_folds.csv` — 1,323 rows (`row_index`, `entry_id`, `label`, `fold` 1–5);
  `StratifiedKFold` stratified on the binarized easy-axis label.
